Corresponding source accompanies the binaries in Source.tar.gz: G Boy plus the
complete pinned JUCE source and build scripts. Build using CMake 3.22 or newer:
  cmake -S G-Boy -B build -DJUCE_SOURCE_DIR=<absolute path to extracted JUCE>
  cmake --build build --config Release
